# Swift-Load Logistics — DSA Final Assignment

**Unit 19: Data Structures & Algorithms**  
Academic Year 2025–2026 | Spring Semester

---

## Overview

A C++ implementation of core data structures and algorithms applied to a logistics cargo management scenario. Built for the Unit 19 final assignment at Saigon Business School.

---

## What's Implemented

| Component | Criteria |
|---|---|
| Goods ADT (encapsulation, validation) | P1, M3, D2 |
| FIFO Queue — truck loading bay | M1 |
| Array-based Stack — LIFO cargo loading | P2, P3 |
| Bubble Sort & QuickSort (descending) | M2 |
| AVL Tree — warehouse inventory | P4, M4 |
| Dijkstra's & A* shortest path routing | D1 |
| AVL vs Linear search efficiency analysis | P7, D3 |
| Robust error handling & 10 test cases | P5 |
| Big-O summary, trade-offs, ADT independence | P6, M5, D4 |

---

## How to Compile and Run

```bash
g++ -std=c++17 -O2 -o swift_load main.cpp
./swift_load
```

Requires a C++17-compatible compiler (GCC 7+, Clang 5+, MSVC 2017+).

---

## Test Cases

The program runs 10 test cases automatically on launch covering valid insertions, AVL rotations, search, error handling, sorting, routing, and efficiency measurement. No input required.
